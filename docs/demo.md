# SANAD demonstration

1. Start the app locally (`npm ci`, `npm run dev`), click **Try Demo**. This starts a separate private, fictional local session.
2. The mixed-language worker statement is preloaded. Choose **Understand my situation**. Explain that without an AI key the local rule-based analysis is a simulation; with a configured provider, Zod validates the provider JSON.
3. Review job loss, unpaid August wages and the missing employment end date. Edit/clarify facts, then **Confirm information**.
4. **Issue user-confirmed credential**. Point out its hash, QR and clear Demo/Testnet Simulation label. The record proves a confirmed snapshot was issued, not that the employer actually withheld wages.
5. **Find relevant support**. Show the official MOHRE labour complaint source and other resources, why each matched, and the relevance score disclaimer.
6. Start a SANAD journey with the credential attached. Submit the local simulation; move to under review and additional documents required. A visible status and live region announce the change.
7. Optionally upload a fictional document in Documents, review extracted fields, and attach it to a draft journey.
8. Open the public verification link/QR. It shows issuer/status/integrity, not private facts. Revoke from My credentials, then check the same public link again.

There is no real government filing in this flow. Amoy testnet use requires the separately configured issuer wallet and deployed contract.
